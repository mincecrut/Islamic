# Нур — исламский сайт

Статический сайт без сборки. Работает на GitHub Pages.

## Что внутри

- **Коран**: все 114 сур, арабский текст (Усмани), перевод Э. Кулиева, чтение вслух (Мишари аль-Афаси), закладки и «Продолжить чтение».
- **Время намаза** по городу или геолокации, ближайший намаз, дата по хиджре, дни до Рамадана.
- **Кибла**: направление на Каабу и компас телефона.
- **Тасбих**, азкары, дуа, аят дня, хадис дня.
- **99 имён Аллаха** и пять столпов ислама.

Текст Корана, перевод, аудио, время намаза и имена Аллаха подгружаются из интернета:
`api.alquran.cloud`, `cdn.islamic.network`, `api.aladhan.com`. Без интернета эти разделы не загрузятся.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub (например, `nur`).
2. Загрузите в него файлы `index.html`, `style.css`, `script.js`, `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Через минуту сайт будет доступен по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

### Через Termux

```bash
pkg install git
git init
git add .
git commit -m "Исламский сайт"
git branch -M main
git remote add origin https://github.com/<ваш-ник>/<репозиторий>.git
git push -u origin main
```

## Как менять содержимое

Тексты аятов дня, хадисов, зикров и дуа находятся в начале `script.js` в массивах `AYAT`, `HADITHS`, `DHIKR`, `DUAS`.
